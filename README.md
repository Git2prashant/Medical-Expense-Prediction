# 🏥 Medical Expense Prediction

> **Predict a person's annual medical insurance charges using Machine Learning**

---

## 📋 Project Overview

Insurance companies don't charge everyone the same. Your premium and expected medical cost depend on factors like your age, BMI, whether you smoke, and your region.

This project builds a **Linear Regression model** that takes a person's details and **predicts their yearly medical charges (in dollars)**.

- **Problem Type:** Supervised Learning → Regression
- **Algorithm:** Linear Regression (primary), Random Forest (bonus comparison)
- **Dataset:** [Medical Cost Personal Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance) — 1,338 samples

## 📊 Dataset

| Column     | Type        | Description                              |
|------------|-------------|------------------------------------------|
| `age`      | Numeric     | Age of the person                        |
| `sex`      | Categorical | male / female                            |
| `bmi`      | Numeric     | Body Mass Index                          |
| `children` | Numeric     | Number of dependents                     |
| `smoker`   | Categorical | yes / no                                 |
| `region`   | Categorical | northeast / northwest / southeast / southwest |
| `charges`  | Numeric     | **Target** — Annual medical cost (USD)   |

---

## 🧠 Model Pipeline

1. **Load** `insurance.csv`
2. **Explore** — distributions, correlations, feature relationships
3. **Encode** — Binary encode `sex` & `smoker`, one-hot encode `region`
4. **Split** — 80% train / 20% test (random_state=42)
5. **Train** — Linear Regression
6. **Evaluate** — R², MAE, RMSE, actual vs predicted plots, residual analysis
7. **Predict** — For new, unseen person data

---

## 📈 Results

| Metric | Linear Regression | Random Forest |
|--------|------------------|---------------|
| R²     | ~0.75            | ~0.85         |
| MAE    | ~$4,000          | ~$2,500       |
| RMSE   | ~$6,000          | ~$4,500       |

**Key Finding:** Smoking status is the strongest predictor of medical charges, followed by age and BMI.
